ABOUT MY OC TEMPLATE

建立自己的 OC 網站

複製一份空白模板後，你會擁有自己的 repository、網頁編輯器、OC 資料與公開網址。每個人的網站彼此獨立，不會覆蓋其他人的內容。

OC
1

建立自己的 repository

登入 GitHub 後按「使用模板建立」，設定自己的 repository 名稱。無法使用模板按鈕時，可以先改用 Fork。

2

開啟 GitHub Pages

到新 repository 的 Settings → Pages，選擇 Deploy from a branch、main 和 / (root)。

3

打開自己的編輯器

在自己的公開網址後加上 editor.html，便能用表單建立世界、角色與 IF 線。

4

發布並分享

在編輯器按「複製並打開 GitHub」提交 data.js。公開頁面只供觀看，訪客不能修改你的原網站。

INDEPENDENT SITES

多人公開，但資料不混在一起

每位創作者都從模板建立自己的 repository，因此每個人都有獨立權限、圖片、內容與網址。分享時只需要傳送自己的 GitHub Pages 網址，不需要把觀看者加入 Collaborators。
